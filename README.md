# STM-harmonyos-car — QST"先锋号"鸿蒙智能小车实训

北京航空航天大学 2026 实训项目：基于 **Hi3861（OpenHarmony / LiteOS-M）+ STM32F103** 双核心架构的智能运动小车。

## 最终目标

1. 无干扰环境下**直线行驶**
2. **不停止移动**的情况下，狭窄空间内**不碰撞**
3. **迷宫中自动找到出口**（智能导航）

## 系统架构

```
┌─────────────────────────────┐     UART 协议通信    ┌─────────────────────┐
│ Hi3861（主核心/OpenHarmony） │ ◄─────────────────► │ STM32（从核心/裸机）  │
│ 业务逻辑、运动决策、数据收发   │                     │ 运动执行：双电机 PWM   │
│ 红外/超声波/舵机/OLED/蓝牙/   │                     │ （L9110S）+ 双编码器   │
│ WiFi/温湿度/光照度           │                     │ 测速、NFC、WS2812 灯带 │
└─────────────────────────────┘                     └─────────────────────┘
```

调试链路：CH340 串口（板载开关选择连接 Hi3861 或 STM32）+ ST-Link/SWD（STM32 下载调试）。

## 仓库内容

| 路径 | 说明 |
|---|---|
| `print_io/` | STM32 Keil MDK 工程：WS2812 双灯带驱动（缓冲-刷新分离设计）+ **串口命令灯效系统**（逐字节前缀匹配状态机 + 非阻塞单帧动画，新命令可随时打断切换） |
| `motor_pwm/` | 任务21-24 合体工程：TIM4 双路 1kHz PWM 电机驱动 + TIM2/3 编码器测速 + 增量式 PID 双轮速度闭环 + 行程状态机 + 双核 UART 通信协议（帧校验/ACK/300ms 运动租约） |
| `nfc_card/` | 任务20 NFC 读卡工程：UART2 驱动 PN532，按帧结构状态机解析（LCS/DCS 校验），卡号命中边沿触发用户函数 |
| `Demo_Code/` | STM32 标准外设库示例工程 |
| `学习记录.md` | 实训理解性笔记：内存映射 IO 与位带、WS2812 时序、RTOS 线程/互斥锁/软件定时器机制、定时器 PWM 调速原理等——按日期沉淀"为什么" |
| `main_work.md` | 已入库代码的工作记录 |

## 当前进度

- **STM32 侧**：开发环境与 ST-Link 下载打通；串口命令灯效系统；TIM4 双路 PWM 电机驱动 ✅；TIM2/3 编码器测速 ✅；增量式 PID 双轮速度闭环 + 前进 1 米倒退 1 米行程状态机（平地实机通过）✅；NFC 读卡 ✅；双核 UART 通信协议（STM32 侧，CH340 模拟 + 真双核落地实测均通过）✅
- **Hi3861 侧**：OpenHarmony 编译烧录链路打通；任务管理/软件定时器/互斥锁/消息队列 API 实践；红外对管、SG90 舵机、HC-SR04 超声波、UART 蓝牙、OLED（I2C/SSD1306，含汉字位图显示）、光照度（AP3216C，与 OLED 同挂 I2C0 多从共存）逐模块实机验证；**阶段一 10 任务全清**，阶段二进行中（任务11 OLED / 任务12 SHT20 主线均实机通过；OLED 遥测上屏 + 光照控屏合体实验 8-31 实机通过）
- **进行中**：双核 UART（Hi3861 UART2 ↔ STM32 USART1）协议联调完成，含 STATUS 遥测回报（编码器里程/速度上报）；桌面防坠落实机通过，超声波避障合体工程（防撞+防掉）墙面工况转向验证通过、综合验收进行中
