# STM-harmonyos-car — QST"先锋号"鸿蒙智能小车实训

北京航空航天大学 2026 实训项目：基于 **Hi3861（OpenHarmony / LiteOS-M）+ STM32F103** 双核心架构的智能运动小车。

## 最终目标

1. 无干扰环境下**直线行驶**
2. **不停止移动**的情况下，狭窄空间内**不碰撞**
3. **迷宫中自动找到出口**（智能导航）

## 系统架构

```
┌─────────────────────────────┐     UART 协议通信    ┌─────────────────────┐
│ Hi3861（主核心/OpenHarmony） │ ◄─────────────────► │ STM32（从核心/裸机）  │
│ 业务逻辑、运动决策、数据收发   │                     │ 运动执行：双电机 PWM   │
│ 红外/超声波/舵机/OLED/蓝牙/   │                     │ （L9110S）+ 双编码器   │
│ WiFi/温湿度/光照度           │                     │ 测速、NFC、WS2812 灯带 │
└─────────────────────────────┘                     └─────────────────────┘
```

调试链路：CH340 串口（板载开关选择连接 Hi3861 或 STM32）+ ST-Link/SWD（STM32 下载调试）。

## 当前进度

- **STM32 侧**：开发环境与 ST-Link 下载打通；串口命令灯效系统（自主改造）；**TIM4 双路 1kHz PWM 驱动电机**（实机验证双轮转动）
- **Hi3861 侧**：OpenHarmony 编译烧录链路打通；多线程任务管理；红外对管 + 软件定时器；SG90 舵机云台 + 互斥锁三线程（优先级翻转演示）
- **进行中**：编码器测速（TIM2/TIM3 编码器接口模式）→ 下一步 PID 速度闭环

## 开发环境

- **STM32**：Keil MDK 5 + STM32F10x 标准外设库 + ST-Link
- **Hi3861**：Ubuntu 20.04（VMware 虚拟机）+ OpenHarmony 源码编译链 + HiBurn 烧录
