## 目标

用 TIM4 输出两路 PWM 驱动左右电机，小车按设定速度前进。作业：改速度值观察两轮变化。

## 硬件原理（三条线串起来）

- **L9110S 电机驱动芯片**：每电机两个控制脚——一个 **PWM 脚**（决定速度）、一个**方向脚**（决定正反转）。STM32 引脚驱动能力弱，电机电流走 L9110S 放大
- **PWM 调速原理**：电机线圈是感性负载，电流不能突变——PWM 高电平时加速、低电平时靠自感电流续转，一个周期内的**平均电压** ≈ 占空比 × 电源电压，占空比 = 速度
- **引脚映射**（原理图 + 参考代码对应）：
  - 左电机：PWM = **PB7**（TIM4_CH2），方向 = **PB14**
  - 右电机：PWM = **PB6**（TIM4_CH1），方向 = **PB13**
  - 参考代码里 A 组（AIN+PWMA）= 右电机，B 组（BIN+PWMB）= 左电机；`Set_Pwm(moto1, moto2)` 的 moto1→左、moto2→右

## 关键参数（背下来）

- PWM 频率 **1000 Hz**：`频率 = 72MHz / (PSC+1) / (ARR+1)` → PSC=9、ARR=7199（72M/10/7200=1000）
- 占空比 = `比较值 / (ARR+1)`：`Set_Pwm(2500,2500)` ≈ 35%；**比较值不能超过 7199**
- 反转写法：方向脚置 1，且比较值写 `7199 - |moto|`（PWM 波形反相，低速反向 = 大占空比）

## 代码结构（在 print_io 模板上加）

| 文件 | 内容 |
|---|---|
| `motor.c/.h`（新写） | `Motor_Init()`：PB13/PB14 推挽输出，初值 0；`PWM_Init(arr,psc)`：PB6/PB7 复用推挽 + TIM4 时基 + CH1/CH2 PWM1 模式 + 预装载使能；`Set_Pwm(int,int)`：符号定方向、绝对值定占空比 |
| `main.c`（改） | 在 print_io 现有初始化后加 `PWM_Init(7199,9)`，主循环 `Set_Pwm(2500,2500)` + `delay_ms(100)` |

- `PWM_Init` 里的初始化顺序：GPIO 复用 → `TIM_TimeBaseInit` → `TIM_OC1Init/OC2Init`（PWM1 模式、极性高、初值 0）→ `TIM_CtrlPWMOutputs` → CH 预装载 → ARR 预装载 → `TIM_Cmd` 使能
- 标准库函数 `TIM_SetCompare1/2(TIM4, x)` 就是运行时改占空比的入口（参考代码用宏 PWMA/PWMB 封了一层）

## 坑 & 注意

- **免开 Keil 界面的命令行编译**（8-26 验证）：`"C:\Keil_v5\UV4\UV4.exe" -b Template.uvprojx -j0 -o build_log.txt`（在 `USER/` 下跑），退出码 0 + 日志 `0 Error(s)` 即过；改完代码先 CLI 编一遍再开 Keil 下载
- **烧录和跑电机的供电是两回事**：USB 数据线能烧录，但**电机电流走电池供电**——烧录时关电池，跑电机时开电池
- 架空测试时车轮空转属正常；**别一上来放地上**——PWM 接错/方向反了车会窜出去
- `JTAG_Set(SWD_ENABLE)` 必须在（print_io 已有），否则 SWD 调试口被关，ST-Link 连不上
- TIM4 挂在 **APB1**（36MHz 域，但定时器时钟 ×2 = 72MHz），GPIO 在 APB2——两条时钟使能别写错（参考代码 `RCC_APB1Periph_TIM4` + `RCC_APB2Periph_GPIOB`）
- 复位键会同时复位 STM32 和 Hi3861；串口开关位置影响的是 CH340 连谁，与烧录无关
