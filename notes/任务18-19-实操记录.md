# 任务18/19 实操记录（2026-08-25）

> 环境：Win11 + Keil MDK 5.25（教育版已激活）+ ST-Link/V2 + QST 先锋号小车。
> 本文记录**实际动手的流程和踩过的坑**；官方标准步骤以 U+ 任务18/19 文档为准。

## 任务18：STM32 环境搭建 + 实机下载

1. 装 Keil MDK 5.25（教育邮箱注册激活，无 32K 编译限制）+ STM32F1xx_DFP.1.0.5 pack。
2. ST-Link 驱动（关键坑都在这）：
   - 插上 ST-Link 落「其他设备 → STM32 STLink」，代码 28 = 没装驱动，**正常**
   - 设备管理器 → 更新驱动程序 → 浏览我的电脑 → 指向：
     `C:\Program Files (x86)\STMicroelectronics\STM32 ST-LINK Utility\ST-LINK_USB_V2_Driver`
   - 成功标志：出现「STMicroelectronics STLink dongle」
   - ❌ 别用文件夹里的 `ST-Link_V2_USBdriver.exe`（老 1.04 驱动，Win10/11 装上有记录但不生效）
   - ❌ 别跑 `stlink_winusb_install.bat`（Win8 时代逻辑，在 Win10/11 会错误地走老驱动）
   - 分发：`tools/ST-LINK_USB_V2_Driver.zip`（8 个文件全，含 .cat 签名）
3. Keil 魔法棒 → Debug 选 **ST-Link Debugger** → Settings 读到 `IDCODE 0x1BA01477` = SWD 链路通。
4. Flash Download 页添加 **128KB** Flash 算法。
5. 编译 0 Error → LOAD → **Erase/Programming/Verify OK** = 下载成功（`Target DLL has been cancelled` 那次是取消，不算失败）。
6. 供电顺序：下载前先关小车电源再插 ST-Link；下载完先拔 ST-Link USB，再开小车电源、按复位。
   ST-Link/串口线都是即插即拔，无需"安全删除硬件"。

## 任务19：串口收发打印（print_io 工程）

接线与识别：

- Type-C 线插小车，**串口切换开关打到 STM32 端**，小车通电
- 设备管理器「端口 (COM 和 LPT)」出现 `USB-SERIAL CH340 (COMx)`（本次为 COM3）
- 坑1：CH341SER 显示「预安装成功」是正常的——驱动只是预置进系统，**插线那一刻才出现 COM 口**
- 坑2：ST-Link/V2 是纯调试器、不带虚拟串口，插它不会产生 COM 口
- 坑3：「通用串行总线控制器」里永远看不到 CH340 的名字，别去那找

UartAssist 流程：

1. 串口号选 COMx；参数 115200 / NONE / 8 / 1 / NONE（对应程序 `uart_init(115200)`）
2. **先点「打开」**——按钮变「关闭」才算占上串口。不打开就点发送会报「发送失败，串口未连接或已经拔出！」
3. 按一下小车**复位键** → 日志区收到 `QST青软`
4. 发送区清掉默认的 `http://www.cmsoft.cn`，ASCII 模式发 `HELLO` → 跑马灯起跑
   （若「打开」报被占用：检查 HiBurn / 其他串口工具是否已占着该 COM）

程序逻辑（`print_io/USER/main.c` + `print_io/SYSTEM/usart/usart.c`）：

- 上电：8MHz×9=72MHz、USART1@115200、关 JTAG 开 SWD、炫彩灯初始化，`printf("QST青软\r\n")`
- USART1 中断：`H` 开头计数，第 5 字节为 `O`（即收到 "HELLO"）→ `USART_RX_STA=1` → 主循环调 `L_runingled()`

学生作业（待做）：

1. 定时发送数组 `0x01 0x02 0x03 0x04 05`（长度 5）给电脑；电脑端串口助手需勾 **HEX 显示** 才能正常看
2. 电脑发 HEX `01 02 03 04 05`，小车判断正确则点亮跑马灯

## 灯效扩展：串口命令切换（2026-08-25）

在 print_io 工程上做的创新改动（编译 0 Error 0 Warning）：

- **命令表**：`HELLO`（原版跑马灯）、`ALLON`（12颗全亮）、`BLINK`（同步闪烁 300ms）、`RAIN`（7色循环换色）、`FLOW`（白点流水扫过12颗）、`OFF`（全灭）
- 结构：串口中断按命令表做前缀匹配，完整命中置 `LED_CMD` + `USART_RX_STA`；主循环取命令后**清零 `USART_RX_STA`**，按 `led_mode` 分发到非阻塞"单帧"灯效函数（`fx_*_frame`，内部自带动画延时），随时可切换
- 改动文件：`SYSTEM/usart/usart.c/.h`（命令解析）、`QST_HARDWARE/colorful_led/colorful_led.c/.h`（新灯效 + `led_all_on/off`）、`USER/main.c`（模式分发）；原 `L_runingled()` 等老代码保留未删
- 硬件事实：WS2812 两条灯带，前 L=PC13、后 R=PC14，各 6 颗，GRB 高位先发，0码 400/850ns、1码 850/400ns、复位 66µs
- 编辑注意：源码是 **GB2312 编码**，自动化编辑需 iconv 转 UTF-8 → 改 → 转回 GBK（否则 Keil 里中文注释乱码）
- 已知限制：WS2812 位拍打期间若来串口中断可能花屏一帧，下一帧自愈，演示可忽略
